# TOB PAWN SHOP — ระบบตรวจสอบยอดจำนำ

เว็บสำหรับลูกค้ากรอกเลขไอดี (เช่น `ID00`) เพื่อดู:

1. เลขไอดีลูกค้า, ชื่อ, รายการทรัพย์ที่นำมาจำนำทั้งหมด และยอดค้างชำระ
   (คำนวณดอกเบี้ยทบต้นรายวัน 3% ตั้งแต่วันฝากจนถึงวันปัจจุบัน หรือวันที่ยอดคงเหลือเป็น 0)
2. ดาวน์โหลด **Full Daily TOB Report** — รายงานรายวันฉบับทางการ พร้อมโลโก้ร้าน
   สรุปยอด เงื่อนไข และช่องลงนาม (เปิดไฟล์แล้วสั่งพิมพ์เป็น PDF ได้)

## วิธีใช้งาน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย (หรือเปิดผ่าน GitHub Pages)
ไม่ต้องติดตั้งอะไรเพิ่ม

## สำหรับแอดมิน — หน้าหลังร้าน (`admin.html`)

เปิด `admin.html` แล้วล็อกอินด้วยชื่อแอดมิน + รหัส PIN จะทำได้ทั้ง:

- เพิ่ม/แก้ไข/ลบลูกค้าและรายการฝาก-คืน พร้อมระบุ**แอดมินผู้เก็บของ**ในแต่ละรายการ
- กด **"🚀 บันทึกขึ้นเว็บจริง"** — ระบบจะ Commit ไฟล์ `data.js` ขึ้น GitHub ให้เอง
  และ**สำรองไฟล์เก่าไว้ในโฟลเดอร์ `backups/` ทุกครั้ง**ก่อนเขียนทับ
  หน้าเว็บลูกค้าอัปเดตอัตโนมัติใน 1–2 นาที
- ปุ่ม "ดาวน์โหลดไฟล์สำรอง" ใช้โหลด data.js มาเก็บไว้ในเครื่องเอง (ทางเลือก)

ข้อมูลที่กำลังแก้จะถูกจำไว้ในเครื่องเป็นฉบับร่าง จนกว่าจะกดบันทึกขึ้นเว็บจริงหรือล้างฉบับร่าง

### การตั้งค่า GitHub Token (ครั้งแรกของแต่ละเครื่อง)

1. เข้า GitHub → Settings → Developer settings → **Personal access tokens → Fine-grained tokens** → Generate new token
2. Repository access: เลือก **Only select repositories** → เลือก repo นี้
3. Permissions → Repository permissions → **Contents: Read and write** (อย่างอื่นไม่ต้อง)
4. Generate แล้วคัดลอก Token มากดปุ่ม **"⚙ ตั้งค่า GitHub Token"** ในหน้าแอดมิน แล้ววาง

Token เก็บอยู่ในเครื่องที่กรอกเท่านั้น ไม่ถูกฝังในโค้ดสาธารณะ

## สำหรับแอดมิน — แก้ `data.js` ตรง ๆ (ทางเลือก)

แก้ไขไฟล์ **`data.js`** ไฟล์เดียว (ข้อมูลตรงกับไฟล์ `ID00.ชื่อ.xcl` ใน Drive):

```js
{
  id: "ID00",            // เลขไอดีลูกค้า
  name: "ชื่อ",           // ชื่อลูกค้า
  transactions: [
    { date: "2026-07-01", type: "ฝาก", item: "Lunar Dagger", amount: 1000000 },
    { date: "2026-07-04", type: "คืน", amount: -592727 },   // คืนใส่ค่าลบ
    { date: "2026-07-05", type: "คืน", amount: -515000 },
  ],
}
```

เพิ่มลูกค้าใหม่ = คัดลอกบล็อกด้านบนไปวางต่อท้ายใน `CUSTOMERS` แล้วแก้ข้อมูล

## กติกาดอกเบี้ย

- ดอกเบี้ยทบต้นรายวัน **3%** ของยอดค้างมัดจำ เริ่มคิดวันถัดจากวันฝาก
- วันที่มีการชำระคืน คิดดอกเบี้ยของวันนั้นก่อน แล้วจึงหักยอดคืน
- หยุดคำนวณเมื่อถึงวันปัจจุบัน หรือเมื่อยอดคงเหลือเป็น 0 / ติดลบ
